NUTRI NEST — STATIC WEBSITE
============================

Contents:
- index.html: single-page website
- styles.css: responsive styling (desktop, tablet and mobile)
- script.js: mobile navigation and current footer year
- assets/: product photos supplied for the website

Preview:
Open index.html in a browser. No build step or backend is required.

Deploy:
Upload the contents of this folder to the public web root of your hosting provider
(e.g. public_html). Keep the assets folder beside index.html.
